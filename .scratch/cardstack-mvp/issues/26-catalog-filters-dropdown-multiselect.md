# 26: Catalog filters: dropdown multi-selects with chips instead of always-open checkbox lists

**Category:** enhancement
**Status:** ready-for-agent

**Blocked by:** None (can start immediately)

## Agent Brief

**Category:** enhancement
**Summary:** Each faceted catalog filter (Expansion Set, Rarity, Category, Tag) becomes a dropdown trigger that opens a checkbox list, with the selected values shown as removable chips, instead of every option being rendered inline.

**Current behavior:**
- `FacetFilters` (`frontend/src/components/catalog/facet-filters.tsx`) renders every option of all four filters as an always-open checkbox list. With about 94 Expansion Sets grouped under Series plus Rarity, Category and Tag, the filter panel is very long and hard to scan.
- `frontend/src/components/ui/` has no popover or combobox component. `@base-ui/react` is already a dependency and provides them.

**Desired behavior:**
- Each of the four filters is one dropdown trigger (label plus a count badge of selected values). Opening it shows a checkbox list; the dropdown stays open while the user toggles several values.
- The Expansion Set dropdown has a text search box that narrows the visible options, and keeps the Series grouping (including the ungrouped ones). The other three dropdowns do not need search.
- Selected values from all four filters are shown as chips near the filters, each removable with one click, so the active selection is visible without opening any dropdown.
- Behavior from ticket 21 is unchanged: multi-value OR within a filter and AND across filters, faceted option availability, selected-but-unavailable values stay visible and checked so they can be unchecked, selections live in the URL search params, and the Collection detail page uses the same panel.
- The panel is keyboard accessible (open, move, toggle, close) and works at phone width.

**Key interfaces:**
- `FacetFilters` and `CatalogFilterPanel` keep their props, so the catalog page and the Collection detail page need no changes.
- New shared UI component(s) built on `@base-ui/react` (popover or combobox), added under `frontend/src/components/ui/` following the existing shadcn style.

**Acceptance criteria:**
- [ ] The four filters render as dropdowns with a count of selected values, not as always-open checkbox lists
- [ ] The Expansion Set dropdown has a search box and Series grouping
- [ ] Selected values appear as removable chips, and removing a chip updates results and the other filters' options
- [ ] Unavailable-but-selected values stay visible and checked inside their dropdown
- [ ] Multiple selected values still round-trip through the URL
- [ ] Both the catalog page and the Collection detail page use the new panel
- [ ] Frontend tests cover opening, toggling, searching, chip removal and the unavailable-selected case, and the existing catalog search e2e spec is updated; both verification scripts pass

**Out of scope:**
- Facet counts next to each option
- Backend or API changes
- Guest limits on filtering (ticket 24)
