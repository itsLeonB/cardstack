# 34: Virtualized grid accessibility, focus and scroll restoration

**Category:** enhancement
**Status:** ready-for-agent

**Blocked by:** 33

Findings: `.scratch/cardstack-mvp/research/virtualized-infinite-scroll.md` (sections 2, 3, 6 and 7). Ships together with ticket 33.

## Agent Brief

**Category:** enhancement
**Summary:** Make the virtualized card grid usable with a keyboard and a screen reader, keep the user's place when columns change or when navigating back, and cover it with tests.

**Current behavior:**
After ticket 33 the grid virtualizes, which unmounts offscreen tiles. That breaks focus on an unmounted tile, loses list position information for assistive tech, shifts the viewport when the column count changes on resize, and does not restore the scroll position on back navigation.

**Desired behavior:**
- List semantics survive virtualization: each tile exposes its position and the total (`aria-posinset`/`aria-setsize`) so a screen reader knows it is item N of total, using the markup the research recommends (a list with presentational row wrappers and list items).
- A focused tile (or control inside it, such as the quantity buttons) is never unmounted while it has focus; tabbing out of the last rendered tile reaches the "Load more" button, and the next Tab reaches the footer.
- When the column count changes on resize, the viewport stays anchored on the same card (the research found a synchronous re-anchor lands about 15 rows off and a one-frame deferral fixes it).
- Back navigation from a card detail page returns to the same scroll position with the previously loaded pages, using the router's scroll restoration for window scroll.
- Reduced-motion preference is respected for any scroll animation.

**Key interfaces:**
- The virtualized grid component from ticket 33 (range extraction, scroll margin, restoration offset).
- The router's scroll restoration and the default query cache lifetime for the catalog query.

**Acceptance criteria:**
- [ ] A screen reader (or the accessibility tree in Playwright) reports each tile's position and the total
- [ ] Keyboard: Tab through tiles never loses focus when rows unmount; the button after the list and then the footer are reachable (Playwright)
- [ ] Resizing across a column breakpoint keeps the same card in view
- [ ] Opening a card and going back restores the scroll position and the loaded list (Playwright)
- [ ] An axe check on the results passes
- [ ] Both verification scripts pass

**Out of scope:**
- Expansion Set page, Collection entries and Master Inventory: tickets 35 and 36
- Browser find-in-page for unrendered tiles (a known limitation of virtualization; record it, do not work around it)
