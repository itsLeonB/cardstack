# Catalog rows record who created and last updated them, and no writer overwrites another's

The Pokémon Asia site is missing cards and sets (TCG Collector's Indonesian listing has hundreds more cards in sets we already hold, and a few whole sets), so TCG Collector becomes a second ingestion source that fills only what the catalog lacks. With three writers (the Asia scraper, the TCG Collector ingester and the Admin of ADR-0019), the `curated` boolean cannot say whose row it is, so `cards` and `expansion_sets` get two text columns, `created_by` and `updated_by`, each holding one of `pokemon-asia`, `tcgcollector` or `admin`. They hold a Source (GLOSSARY.md), not a user.

One rule governs every writer: a writer changes a row only while `updated_by` is itself, and never changes a row it did not create or last update. The Asia ingester inserts with both columns `pokemon-asia` and keeps updating its own rows on rerun. The TCG Collector ingester only inserts (both columns `tcgcollector`) and skips any Card or Expansion Set that already exists, whoever wrote it. An Admin write sets `updated_by = admin`, which takes the row away from both ingesters; this replaces `curated`, which migrates to `updated_by = admin` (production has no curated rows today). This changes ADR-0019 only in that its boolean becomes this pair; the Admin may still write any row.

The one exception is the set logo: TCG Collector fills `source_logo_url` and `logo_key` of any Expansion Set while they are empty, without touching `updated_by`, so the Asia ingester can still update its own set row. The API returns the logo where it has one and the Asia cover otherwise.

Identity across Sources is the Expansion Set code and the Card's number within the set. TCG Collector set names are English translations, so names never match. Its promo codes lose their dash (`SMP` for `SM-P`) and three Sun & Moon deck codes carry an extra `i` (`AS4Di` for `AS4D`), so a small alias table normalises codes before the match. Numeric Card numbers compare as integers (`1` equals `001`) and new ones are stored zero-padded to the set's existing numeric width, default 3. Asia stores Basic Energy under a type code (`FIR`) and the Victory Symbol under the set code, while TCG Collector numbers them, so those two are skipped in a set that already exists, or the same card would be inserted twice.

A set that TCG Collector creates because no Source had its code is added unpublished: `expansion_sets.published` is false, the set is hidden from every non-Admin view and from the scan matcher, and the operator sets it true in SQL after checking the Cards. Existing sets are backfilled as published, and a Card added to an already published set is visible at once.

## Considered Options

- Keep `curated` and add a plain `source` column. Rejected: a TCG Collector row an Admin has edited would then have no way to say both facts, and the rule above needs "who last updated it", not "who first made it".
- Let the Asia scraper overwrite TCG Collector rows, since Asia is the official site. Rejected by the operator: neither Source is trusted to correct the other, and a silent overwrite is the failure ADR-0019 already ruled out for hand edits.
- Fetch TCG Collector from a headless browser, or save its pages by hand. TCG Collector answers plain HTTP with a Cloudflare challenge, and its API is for business partners only. We do not build anything that evades the challenge. The ingester drives a visible Chrome with a persistent profile that a person unlocks once, pauses and resumes when the challenge reappears, and keeps a local page cache; `-dir` parses pages saved by hand as the fallback. `robots.txt` bars `?page=` URLs, which no page we need uses. Waiting for a challenge means waiting for the interstitial the site is showing, recognised by Cloudflare's challenge config key or by the `Just a moment` title, and never for Cloudflare's code merely being present: its precursor script and the `window.__CF$cv$params` block ride on every normal page, so reading them as a challenge parks the run on a page a person is already reading, and the fix is to stop reading them that way rather than to delete them from the document.

## Consequences

The migration adds the two columns to both tables, `published` to `expansion_sets` and the logo columns, and the Asia ingester's two upsert functions change from "skip if curated" to the `updated_by` rule. A card row also stores the stripped `<main>` HTML of its TCG Collector page in `raw` (about 17 KB); user-facing card queries already list their columns, and a test keeps `raw` out of them.

Whichever Source wrote a Card first keeps it, so a TCG Collector Card is never replaced if Asia later publishes the same number; fixing one means an Admin edit or a manual database change. Skipping Basic Energy and the Victory Symbol is by name and type, so a differently named duplicate in an existing set would still be inserted; the dry run lists what it would add so the operator can see it. Rarity comes from the code in parentheses on the TCG Collector page and must already exist in `rarities`; an unknown code fails that Card in the report instead of creating a rarity. Challenge detection rests on Cloudflare's interstitial markers alone, so a page reaches the parsers as soon as it shows real content; if the site renames the interstitial title or drops the config key, detection goes quiet and the run fails as a parse error naming the page, not as a run that waits forever.
